# 服务生命周期可靠性验收

本轮在独立状态目录执行。以下结果只覆盖本次测试的进程、容器和原生窗口。

| 范围 | 结果 |
|---|---|
| 后端回归 | 常规 CI 对应的 109 项 Python 测试通过，包含核心采集 20 项。故障注入覆盖日志打开失败、进程创建失败、启动确认超时、监督进程并发完成以及旧版未结束记录。 |
| 真实 Docker | 自动采集夹具 8 项通过。手动登记与自动采集在同一状态库共存，Compose 成员归属正确，重复采集不新增登记。使用已缓存的镜像和休眠入口，清理后核对原有容器状态。 |
| 原生观察器 | 一次性 macOS 应用关闭窗口不触发策略，最后一个实例退出后触发。策略锁忙时可继续写入心跳，慢停止期间心跳更新，混合批次成功、跳过、失败各一项。观察器重启后仍能读取最近结果。 |
| 设置与服务回收 | 独立原生窗口呈现混合结果、跳过原因和结果未确认提示。已删除服务可恢复，重复登记冲突会显示原因并保留归档，未完成的清理可重新进入确认预览。通过隔离后端测试验证永久清理、外部路径、日志引用和部分失败后重试。 |
| 旧数据与构建 | 恢复使用旧版单服务归档结构，验证保留原运行与日志、恢复不启动服务。原生构建及签名检查通过。 |

真实 Docker 测试使用真实容器及合成 hook 输入。退出通知来自测试应用，未退出实际 Codex。设置页的结果未确认场景使用隔离状态夹具。
