# P3 到期调度与历史事件增量缓存

新增附加到期表、可见/隐藏索引及 SQLite 触发器。配置、运行、项目策略和观察投影改变时维护到期状态，先筛选到期记录再最多解码 12 项。优先级排序只作用于到期候选；积压全部到期时仍需排序候选，不声称数据库工作量绝对恒定。共享观察锁、6 线程上限和最终身份/代际核验保持不变。

数据库 user_version 保持 1，旧监督器的写入由触发器维护索引，无需重启业务。首次初始化有一次回填成本，之后稳定历史不重复解析。

事件索引复用未变化文件，删除、替换、内容或权限变化均失效。根身份已经结束、没有保留后代且不在 Docker 关联窗口内的事件退出热集合；仍保留磁盘历史。文件变化或持久跟踪引用会恢复参与。生产采集器不启用，以下事件结果仅来自隔离函数测量。

## 独立组件 CPU 对照

使用真实 SQLite，260/1000/5000 条缓存终态记录，每个版本预热后连续选取 60 次到期工作，按 P2/P3/P3/P2 顺序测量；计入数据库打开、查询和 Python 解析的进程 CPU 时间。

| 服务数 | P2 每次选择 | P3 每次选择 | 降幅 |
|---:|---:|---:|---:|
| 260 | 1.938 ms | 0.403 ms | 79.2% |
| 1000 | 6.273 ms | 0.401 ms | 93.6% |
| 5000 | 30.924 ms | 0.400 ms | 98.7% |

事件文件保持原样，缓存先预热，完整重读与指纹刷新各测 5 次：

| 文件数 | 完整重读 CPU | 未变化指纹刷新 CPU | 降幅 |
|---:|---:|---:|---:|
| 1000 | 31.66 ms | 5.20 ms | 83.6% |
| 5000 | 173.01 ms | 28.10 ms | 83.8% |

所有旧根已结束后，重复选取热事件约 0.001–0.004 ms/次；1000/5000 个原始文件全部保留。指纹刷新仍需枚举文件，通常在目录变化或 60 秒重试时执行。这些是组件 CPU 时间，不能冒充生产采集器驻留占用降幅。

原始数据：本机忽略目录 `.test-state/p3-components.json`。复现使用 `scripts/benchmark_observation.py --baseline-backend <P2 backend> --output <结果路径>`。

## 真实原生 worker 对照

相邻 P2/P3 构建使用相同 1000 条终态缓存、24 项目，开启测试项目观察；每轮开始只把测试缓存检查时间刷新为当前时刻，保留正常 120/240 秒到期规则。正式采集器关闭。预热后 P2/P3/P3/P2 各 30 秒，均收到 15 次刷新，响应均为 813668 字节。此负载衡量大量历史记录尚未到期时的重复调度成本，不等同于 1000 个活跃业务服务。

| 轮次 | 版本 | 界面 CPU | worker CPU | 刷新中位数 |
|---|---|---:|---:|---:|
| 1 | P2 | 2.56% | 5.03% | 75.54 ms |
| 2 | P3 | 2.72% | 3.21% | 73.54 ms |
| 3 | P3 | 2.74% | 3.13% | 72.89 ms |
| 4 | P2 | 2.68% | 5.38% | 76.25 ms |

均值：worker **5.20% → 3.17%，下降 39.1%**；界面 **2.62% → 2.73%**（源码未改，不将波动归因于 P3），合计 **7.83% → 5.90%，下降 24.6%**。刷新中位数均值 **75.90 → 73.22 ms**。CPU 采用 Mach 比例 125/3 换算、单核 100% 口径。数据为 `.test-state/p3-cpu-window/results.json`。

菜单模式 P2/P3 各 60 秒、各 5 次刷新：worker **1.53% → 0.62%（下降 59.2%）**，界面 **0.50% → 0.51%**，合计 **2.03% → 1.13%（下降 44.2%）**。每次仍仅 16 条，响应约 13.8 KB；刷新中位数 **53.36 → 54.16 ms**。此单组对照为短期描述性结果，原始文件 `.test-state/p3-cpu-menu/results.json`。

## 回归与边界

9 项新增回归覆盖全部可见/隐藏间隔、旧写入者的配置/运行/策略失效、事务回滚、删除和恢复、最终代际保护、最多 12 条配置解码及查询索引、事件变化/删除/符号链接、PID 复用、后代和 Docker 窗口保护，以及旧事件不再重复枚举进程。

既有 5 项缓存、11 项观察策略、6 项摘要协议、4 项迁移和 7 项私有存储/保留回归通过。原生构建、签名和两种真实窗口模式通过。没有启动正式或测试采集守护进程，事件处理只在隔离函数测试中验证；不将这些结果称作完整采集器端到端验收。新增测试已接入 CI，未运行远端 CI。

15 项真实进程回归通过，新增用例在监督器已运行后安装索引，确认运行 ID、PID 身份不变、数据库版本仍为 1，原监督器继续写回并正常停止。该用例只操作测试服务。
