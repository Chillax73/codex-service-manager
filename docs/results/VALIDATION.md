# 本机验收结果（脱敏）

验证日期：2026-10-12。实测 Apple Silicon / macOS 15.7.3；构建目标 macOS 13+。

A-01 至 A-16 已在声明的本机范围内通过。测试计数和清理事实由 scripts/export_results.py 从实际证据按白名单导出，见 [validation-summary.json](validation-summary.json)。原始结果仅留本机，不上传个人路径、日志、截图、聊天标识、运行 ID、容器信息或环境值。

| 类别 | 通过数量 | 证据性质 |
|---|---:|---|
| 本机进程 | 14 | 真实进程/端口/信号集成 |
| 前端、Java、Python 项目 | 6 | 实际 npm/Vite、Maven/Spring、WSGI 启动链 |
| Docker/Compose | 15 | 真实对象控制、数据保留、去重与隔离 |
| 容器失败 | 8 | 真实提前退出、端口冲突、历史与清理 |
| 端点/时间/日志 | 9 | 契约单元测试 |
| 原生界面 | 28 | 实际窗口和实际控制操作 |

实际 Codex 应用进程终止后，独立 NSWorkspace 观察器成功停止四项适用服务，每项停止操作仅一次；两个保留对象仍保持原运行，观察器继续存活。没有合成 codex_exit 事件。用户实际确认窗口关闭后仍运行，以及菜单栏详情入口可用；人工观察与自动证据分开标记。

测试进程、三只测试容器、专用卷和本轮登记已清理，原有容器状态未变，Docker 恢复验收前状态。原始测试历史先归档后移除。

## 覆盖边界

- 自动登记依赖项目配套入口；普通未经入口启动的进程只发现。
- 系统菜单栏快捷控制共用已验证控制链，但未逐项重复人工点击。
- Intel、其他 macOS 版本及系统关机完成保证未实测。
- 远程服务不属于当前需求范围。
- 这些是开发机实际验收结果，不代表 GitHub CI 验证。

详细用例见 [验收索引](../../specs/001-service-manager/acceptance.md)。重新执行脚本会生成本机原始证据，发布前重新运行脱敏导出并检查 Git 暂存区。
