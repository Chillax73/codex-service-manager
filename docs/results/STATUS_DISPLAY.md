# 状态显示、筛选与项目汇总验收

日期：2026-10-13（Asia/Shanghai）。开发分支更新，尚未包含在 v0.1.0 标签。本报告只记录本轮界面变更，原版服务控制和真实 Codex 退出证据仍见 [原版验收](VALIDATION.md)。

## 交付行为

服务列表、详情、运行历史使用同一套彩色图标和中文徽标；健康状态单独标明“健康”。运行中/成功/可用为绿色，已退出/已停止/失败/停止失败/不可用为红色，过渡/未知为橙色，未运行/取消/未配置为灰色。已退出/已停止仍保留原状态语义，颜色不把它们改写为失败。菜单栏服务项复用相同颜色和图标映射。

状态筛选包含十一种运行状态，逐项精确匹配，并保留全部/需关注。运行中不混入停止中或停止失败；需关注包含失败、停止失败、未知、健康不可用或带诊断问题的服务。项目、搜索与状态筛选同时生效。

项目栏汇总全部所属服务，显示状态和总数。有运行服务时显示“运行中 N”，有异常时另显示“需关注 N”。没有运行服务时依次考虑启动中、停止中、停止失败、未知、失败；其余静态状态相同时沿用，混合时显示“无运行”；无服务显示灰色“无服务”。服务列表的筛选不会改变项目汇总。

## 本机验证

环境：Apple Silicon / macOS 15.7.3。使用独立测试状态，所有持续测试进程与验收窗口通过 scripts/csm 登记；不使用业务进程执行启停测试。

| 检查 | 实际结果 |
|---|---|
| 构建与签名 | scripts/build.sh 通过，codesign --verify --deep --strict 通过。 |
| 服务颜色 | 真实运行、自然退出、任务成功、失败、手动停止分别显示绿/红/绿/红/红。 |
| 选中行、详情与历史 | 蓝色选中行保留可辨认的状态色；详情与历史同步使用徽标，健康未配置为灰色。 |
| 状态筛选 | 原生筛选器展示全部选项；实际选择运行中、已退出、已停止、需关注后只显示对应对象。 |
| 项目与搜索联动 | 相同已退出筛选在运行服务所在项目无结果，改为运行中后显示所属对象；搜索进一步过滤为零，清空可恢复。 |
| 项目汇总 | 两个项目分别显示运行数量；有失败对象的项目同时显示需关注数量和总数，汇总不随筛选或搜索改变。 |
| 实时刷新 | 停止测试项目唯一服务后，项目自动刷新为红色已停止，运行中筛选同步变空；另一项目保持运行。 |
| 本机安装 | 已更新现有应用，重开实际窗口确认项目徽标及状态筛选器存在。 |
| 清理 | 六项测试服务的运行均结束，子进程及监督器出生身份核对为不存在；独立测试观察器已清理。正式组件保留。 |

原始本机证据为 ignored 的 docs/evidence/status-colors-ui.json 及其中索引的窗口截图，含本机路径和运行元数据，不上传 GitHub。README 的现有公开截图仍是经过隐私复核的原版界面，不能代替本轮截图证据。

## 覆盖边界

菜单栏颜色映射已编译，但本轮尝试入口后未捕获菜单画面，不宣称已完成菜单视觉验收。深色模式、过渡/未知/未运行及健康可达性状态未逐项实测；相关选项和映射存在，不以合成状态冒充真实进程验证。

本轮仅修改 SwiftUI 展示、筛选与项目汇总，没有后端模型变化；没有重新执行全量引擎、Docker 或真实 Codex 退出验收，也不改变自动观察覆盖范围。具体规格与任务见 [验收索引](../../specs/001-service-manager/acceptance.md)、[任务清单](../../specs/001-service-manager/tasks.md)。
