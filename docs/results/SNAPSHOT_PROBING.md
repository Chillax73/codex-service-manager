# 快照与后台探测验收

在同一台 Apple Silicon Mac（macOS 15.8.2）上，用固定的 260 条登记和同一缓存镜像分别采样旧版和新版。每种窗口状态预热 8 秒后采样 24 秒，各重建夹具并重复三次。采样范围包括管理应用、退出观察器、采集器和新状态子进程，CPU 纳入系统记录的已回收子进程时间。

| 场景 | CPU 中位数，占单核 | 审计到的子进程数中位数 | 归因写入中位数 |
| --- | ---: | ---: | ---: |
| 窗口打开 | 0.745% → 0.285% | 404 → 50 | 4,832 KiB → 228 KiB |
| 菜单栏驻留 | 0.238% → 0.089% | 112 → 23 | 820 KiB → 124 KiB |
| 仅后台 | 0.072% → 0.046% | 20 → 8 | 240 KiB → 64 KiB |

旧版窗口 CPU 三次为 0.795%、0.727%、0.745%，新版为 0.285%、0.296%、0.274%。菜单栏旧版为 0.217%、0.248%、0.238%，新版为 0.083%、0.089%、0.118%。两项中位数降幅均超过旧版的全幅波动。仅后台三次均低于旧版范围。子进程计数统计启动的 Python 及 Python 发起的探测命令，退出观察器直接启动的 `ps` 计入 CPU，未计入审计数。写入按进程归因，包含测试计数本身的开销。

窗口内快照应用耗时的三轮中位数分别为 270、252、254 毫秒，改造后为 36、48、34 毫秒。窗口打开和菜单栏驻留的每轮新版采样都只有一个长连接子进程。仅后台状态没有长连接子进程。

| 窗口可见时的状态变化 | 旧版三轮最慢 | 新版三轮最慢 | 验收预算 |
| --- | ---: | ---: | ---: |
| 观察进程退出 | 2.10 秒 | 1.82 秒 | 8 秒 |
| 外部停止容器 | 1.97 秒 | 8.00 秒 | 14 秒 |
| HTTP 健康转异常 | 1.96 秒 | 3.94 秒 | 11 秒 |

容器结果仍在预算内，但比旧版约晚 6 秒出现。需要即时状态时可以手动刷新。上述数据仅比较本次固定夹具。[复验入口和夹具说明](../TESTING.md#快照性能基线)

原始 JSON 在本机 `.test-state/snapshot-before.json` 和 `.test-state/snapshot-after.json`。

原生补测使用长日志验证了服务选择、历史运行日志和滚动位置在菜单栏驻留及窗口重开后保留。终止夹具的状态子进程后，界面显示后台暂不可用，仍可手动刷新暂停项目，自动重连后恢复周期读数。退出管理应用后回收长连接子进程，CLI 列表仍返回实时快照。

Python 后端与采集核心回归、原生应用构建和签名校验均通过。隔离联验还通过了 8 项实际 Docker 采集与控制检查，以及 4 项原生退出观察检查，覆盖窗口关闭、退出期间的心跳、混合退出结果和观察器重启后的结果保留。
